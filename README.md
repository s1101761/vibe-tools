# 台灣自駕懶人旅遊助手（前端原型）

## 如何使用
1. 將 `index.html`、`styles.css`、`app.js` 放在同一個資料夾。
2. 直接用瀏覽器開啟 `index.html` 即可操作。
3. 若瀏覽器限制 `file://` 的部分功能，建議使用 VS Code Live Server 或任何靜態網站伺服器。

## 已實作的前端原型功能
- 旅遊條件表單、偏好選擇與示範行程
- 每日行程切換、行程項目新增／編輯／刪除
- 修改出發地、目的地或天數時，會先提示並重新產生初步行程，避免沿用舊城市行程
- 修改確認提示、行程時間與費用摘要重新計算
- 預算明細、每人費用、預算上限提示
- 瀏覽器 localStorage 自動保存
- JSON 行程備份下載與匯入還原
- 分享當下行程快照網址（透過網址參數攜帶資料；修改後需重新產生）
- 列印／另存 PDF（使用瀏覽器列印功能）
- Google 地圖搜尋／路線連結
- 待確認資訊提示與備選景點

## 重要限制
這是依 PRD 建立的純前端原型，不是完整的正式產品。景點、行程、費用皆以示範資料為主；不包含即時景點資料庫、真實路線距離 API、即時交通、營業時間查核、訂房訂位或 AI 服務。行程生成目前可依出發地、目的地及天數重新產生初步行程，但仍是規則式示範排程，尚未實作完整的自動路線最佳化引擎。分享網址可能很長，且網址內容可被取得網址的人查看。油耗、油價、停車與通行費為估算。


## 字體版本
此版本將先前放大 2 倍的 CSS 字體設定縮回原始大小，並保留路線重新規劃修正。


## 本次更新
- 多日行程會安排晚餐；過夜日以住宿／休息睡覺作為當日最後一項。
- 最後一天安排晚餐、返回出發地，並以回家休息／睡覺作結尾。
- 新增行程的視窗可按「取消」或右上角 X 關閉，不必新增項目。
- 注意：行程仍為規則式示範資料，距離、時間、營業資訊及住宿價格未接即時服務。

## 本次行程生成調整
- 第一天先安排出發縣市的早餐、景點與午餐，再前往第一個目的地住宿，不再只把起點當作出發地址。
- 若隔天要跨縣市，行程會先列出從前一晚住宿地退房出發的交通項目，再依示範行車時間安排抵達後的早餐／早午餐／午餐，避免直接跳到下一個縣市用餐。
- 增加各縣市的候選景點，天數多於縣市數時會依不同造訪日輪替景點，不再直接複製同一天的兩個景點。
- 最後一天仍安排晚餐、返程與抵達後休息；交通時間與景點營業資訊仍是原型示範值，需自行用導航及店家資訊確認，尚未連接即時地圖 API。
- 最後一天若早上沒有跨縣市移動，會在早餐前安排住宿退房、整理行李；若當天一早需跨縣市移動，則以「從住宿地退房出發」的交通項目處理。


### 最後一天返程與晚餐修正
- 最後一天固定於 16:00 從最後旅遊縣市啟程返回起始縣市，符合盡量在 18:00 前出發的需求。
- 晚餐安排在起始縣市，且晚餐項目名稱會明確標示「回到起始縣市後用餐」，不再安排在最後旅遊縣市。
- 返程晚餐時間依示範車程估算；目前尚未串接即時導航，請以實際路況調整。
- 最後一天早上保留退房安排；若當天早上還需跨縣市移動，退房時間會提前。


### 本次更新：重新開啟時重置搜尋紀錄
- 每次以一般網址重新開啟網頁時，會清除上一次儲存在瀏覽器的搜尋／行程紀錄，並回到初始示範狀態。
- 使用分享快照網址開啟時，仍會顯示該網址包含的分享行程，不會被重置覆蓋。
- JSON 備份下載與匯入功能仍可用於手動保存及還原行程。


### 本次更新：顯示當天行程地圖
- 點選「查看當天行程地圖」會開啟目前選取日期的 Google 地圖開車路線，不再把所有天數的行程混在同一條路線。
- 切換第 1 天、第 2 天等日期時，地圖連結會跟著更新。
- 路線以當天的景點與餐飲項目為停靠點；交通描述與住宿休息項目不會直接當成停靠點。
- 起點依第一天出發地或前一天住宿項目推定；若地點名稱不是可辨識地址，仍需在 Google 地圖確認或手動調整。


### 里程與駕駛時間估算修正
- 交通類行程若沒有明確里程，會依示範車程以每分鐘約 0.75 公里估算距離，避免里程卡片固定顯示 0。
- 總駕駛時間改為加總交通項目的預估分鐘數，不再以總里程除以固定速度反推。
- 此為原型估算值，並非即時導航距離或路況；實際路線以 Google 地圖為準。
